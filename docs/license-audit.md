## Redistribution, notices, and marks

- The permissive NGINX BSD-like license requires preserving its copyright/license conditions and disclaimer in source redistributions, and reproducing them in documentation or other materials for binary redistributions. Apache-2.0 components generally require retaining applicable notices and providing the license; inspect each tagged `LICENSE` and `LICENSING.md` for the exact packaged component exceptions before redistributing an image.
- Grafana and Loki's AGPL-3.0-only terms have source and notice obligations when covered software is conveyed. AGPL section 13 additionally requires a modified version that supports remote network interaction to prominently offer those users access to its Corresponding Source. The license text also says mere network interaction without transferring a copy is not itself “conveying”; this is not a determination of whether any particular deployment or combination is a covered modified work. See the [Grafana v12.4.15 license](https://github.com/grafana/grafana/blob/v12.4.15/LICENSE) and [Loki v3.5.7 license](https://github.com/grafana/loki/blob/v3.5.7/LICENSE).
- Grafana Labs states its trademarks are governed separately from the software licenses. Its policy permits certain references for open-source discussion, development, and support, but says other uses need a separate trademark license; it also restricts use implying affiliation or endorsement. See [Grafana Labs Trademark Usage Policy](https://grafana.com/trademark-policy/) and [trademark list](https://grafana.com/trademark-policy/trademark-list/). No Grafana logo asset or branded derivative appears in the checked dashboard JSON.
- Image tags are version tags, not content digests. This compose file does not pin image bytes cryptographically. Also, the upstream source licenses above do not enumerate every library, OS package, or notice embedded in each published image. The exact licenses and notice bundle for all image contents were not confirmed here; a redistribution-ready image SBOM and notices would be needed for that broader claim. The Python `slim` image and `nginx:...-alpine` additionally include distribution/base-image contents whose complete package-level licensing was not inventoried.
- The repository now includes a root MIT `LICENSE` for project-authored source, configuration, dashboard JSON, and documentation. That grant does not relicense third-party software or image contents; upstream components remain under their respective licenses. The copyright attribution is based on the Git author identity (`Thiago Sathler`) and should be corrected before publication if the rights holder is different.
